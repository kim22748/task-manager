# TaskFlow · 과제 관리 홈페이지

과제(Task)를 등록·진행 관리하는 정적 홈페이지의 초기 버전입니다.

## 디자인 시스템 참고
- [Ant Design Pro](https://github.com/ant-design/ant-design-pro) — 레이아웃(좌측 사이더 + 상단 헤더 + 카드 콘텐츠), 색상(Primary `#1677ff`), 상태 태그 스타일을 참고합니다.
- 현재는 빌드 도구 없이 순수 HTML/CSS/JS로 구현했으며, 추후 Ant Design Pro(React/UmiJS)로 이전할 수 있도록 화면 구성을 맞춰 두었습니다.

## 현재 기능
- 첫 화면(`index.html`)은 대시보드(`dashboard.html`)로 바로 이동합니다. 예전 '과제 목록' 화면은 없앴고, 과제 관리는 'AI 과제 목록'에서 합니다.
- 과제별 진행률(0~100%)과 변경 이력: 진행률 등이 바뀔 때마다 날짜와 내용을 자동 기록
- 과제 영구 저장: `server.py`가 `data/tasks.json` 파일에 저장 (서버 없이 열면 브라우저 localStorage 임시 저장)
- 대시보드(`dashboard.html`): 한 화면에 핵심만 모아 보여 줍니다. 상단에 전체·진행 중·게시 대기·게시 완료·마감 지연·평균 진행률 카드(누르면 세부 진행 현황의 해당 상태로 이동), 중단에 상태별 현황·진행률 분포·최근 7일 등록, 하단에 주의 필요(마감 지연·임박)·서비스 게시 완료·최근 변경 이력을 보여 줍니다.
- 내 과제 진행률(`progress.html`): 단계별 현황, 전체/담당자별 평균 진행률, 단계별 과제 목록
- 세부 진행 현황(`overall.html`, 대시보드 하위 메뉴): 전체 과제의 상태별 건수·진행률 분포·과제별 진행률을 한 화면에서 보고, 상태·진행률 구간·검색으로 좁혀 볼 수 있습니다. **내 과제**(담당자 이름이 로그인한 사람과 같은 과제)는 '내 진행률'을 누르면 내 과제 진행률로, **다른 담당자의 과제**는 '세부'를 누르면 과제 상세 페이지로 이동합니다.
- 과제 상세(`task-detail.html?id=<과제id>&from=overall|progress|dashboard`): 올라간 파일·상세 현황·변경 이력을 보여 줍니다. 어디서 왔는지(`from`)에 따라 돌아가기 링크와 사이드바 강조가 바뀝니다. 로그인했을 때 다른 담당자의 과제는 **조회 전용**(파일 올리기·삭제 숨김)이고, 사이트관리자는 모든 과제를 수정할 수 있습니다. 내 과제에는 '내 과제 진행률에서 보기' 버튼이 나옵니다.
  - 보여 주는 것: 상세 현황(담당자·진행률·게시일·승인자·게시 사유), 변경 이력, 첨부 파일
  - 첨부 파일은 올리기(끌어다 놓기), 내려받기, 삭제를 할 수 있습니다.
  - 필수 첨부 3종(기획서 hwpx·실행 html·데이터 csv)은 확장자로만 확인합니다.
  - 서버로 실행하면 `data/files/`에 저장됩니다. GitHub Pages처럼 서버 없이 열면 그 브라우저(IndexedDB)에만 저장됩니다.
- AI 과제 목록(`ai-projects.html`, 좌측 메뉴 'AI 과제 목록'): 명칭·목적·분류·단계·과제책임자·소속부서·접근권한범위 등록 게시판. 신규작성/수정은 같은 Modal 창을 사용하고, 수정은 기존 자료를 덮어씀
  - **중복 막기**: 명칭 + 과제책임자가 같으면(앞뒤·연속 공백, 영문 대소문자 무시) 신규작성·수정·엑셀 올리기 모두 등록하지 않습니다.
  - 사이트관리자 전용(`msms/`에서 옮겨 옴): **엑셀로 저장**(`AI과제목록_YYYYMMDD.xlsx`), **양식 내려받기**, **엑셀 올리기**(검사 결과 창에서 틀린 행·중복 행과 이유를 확인한 뒤 등록, 한 행이라도 틀리면 아무것도 등록하지 않음), **체크박스 선택 삭제**
  - 엑셀 파일: 열은 `명칭·목적·분류·단계·과제책임자·소속부서·접근권한범위`, 분류·단계·접근권한범위 드롭다운 포함. 머리글 이름은 `과제명`·`부서`처럼 비슷한 이름도 받고, 내용 없는 줄(서식만 있는 줄 포함)과 `(예시)` 줄은 건너뜁니다. `.xlsx`만, 5MB·내용 있는 줄 1000행까지. 외부 라이브러리 없이 처리(`xlsx_util.py`)하며 셀은 텍스트로만 써서 수식으로 실행되지 않습니다.
- 로그인·사용자 관리(A01, `msshinlh/`에서 옮겨 옴): 로그인(`login.html`), 회원가입(`signup.html`, 사이트관리자 승인 후 사용), 내 정보·비밀번호 변경(`mypage.html`), 사이트관리자 전용 사용자 관리(`admin-users.html`: 가입 승인·역할 지정·비활성화·비밀번호 초기화·처리 이력)
  - 서버로 실행하면 모든 화면과 과제 API가 로그인을 요구합니다. 로그인하면 사이드바에 '계정' 메뉴, 머리글에 이름·역할·로그아웃이 붙습니다.
  - 역할별 권한(서버에서 검사): 조회와 AI 유사과제 묶기는 모든 역할, 과제·AI 과제 등록·수정·삭제·첨부는 사이트관리자·과제책임자, 서비스 게시·해제·사용자 관리·사이트 설정은 사이트관리자만
- 유사과제 탐색(`similar.html`, A04 — `kimyd/similar-llm`에서 옮겨 옴): 기본은 **AI(LLM) 묶기**. 'AI로 유사과제 묶기'를 누르면 LLM이 과제명(과 '메모'를 체크하면 메모)을 읽고 비슷한 과제를 묶어 그룹명·묶은 이유를 씁니다. AI를 쓸 수 없으면(서버 없음·AI 연결 안 됨) 단어 겹침으로 계산하는 키워드 방식을 참고용으로 보여 줍니다.
  - AI 묶기 결과와 그룹 확정 내용은 **각자 브라우저에만 저장**되고 다른 사람과 공유되지 않습니다.
  - 과제명(과 메모)이 **외부 AI 서비스로 전송**됩니다. 지금은 더미데이터 탐색용으로 허용했습니다(2026-11-13 결정). 실제 업무 자료는 보안 반출 승인 후에만 씁니다.
- 사이트 설정(`settings.html`, 사이트관리자만): 유사과제 탐색에 쓸 AI 서비스를 연결합니다. **Anthropic** 또는 **OpenAI 호환**(OpenAI·vLLM·Ollama 등) 주소, 모델, API 키를 넣고 '연결 테스트'로 확인합니다.
  - 키는 `data/llm_config.json`에만 저장되고 화면에는 끝 4자리만 보입니다. 서비스 종류나 주소를 바꾸면 키를 다시 넣어야 합니다(저장된 키가 다른 주소로 가지 않게).
  - 서버 환경 변수 `ANTHROPIC_API_KEY` / `OPENAI_API_KEY`가 있으면 그 키가 우선합니다.
  - **작업 기록** 탭(`settings.html#log`): AI 과제 삭제(1건·선택 삭제)와 엑셀 올리기를 일시·처리자·건수·과제명(올리기는 파일명도)으로 보여 줍니다. 기록은 `data/work_log.jsonl`.
- 더미데이터(`demo-data.json`): 가상 사용자 10명, AI 과제 10건, 과제 10건. 과제 담당자·AI 과제 책임자는 더미 사용자 이름과 같습니다. 날짜는 열 때마다 오늘 기준으로 맞춰집니다.

## 실행 — 실제 동작 확인 (8885 서버)
```bash
cd task-manager
python3 server.py              # Python 3.7 이상 (python3 가 3.6 이면 python3.12 등으로 실행)
python3 server.py --reset-demo # 데이터를 더미데이터로 되돌리고 시작
```
브라우저에서 http://localhost:8885 으로 접속해 로그인합니다. (Python 표준 라이브러리만 사용, 설치 필요 없음)

| 시연 계정 | 역할 | 비밀번호(공통) |
|---|---|---|
| 100001 김하늘 | 사이트관리자 | `Lh!2026pw` |
| 100002 이도윤 | 과제책임자 | `Lh!2026pw` |
| 100003 박서준 | 과제참여자 | `Lh!2026pw` |

- 처음 실행하면 `data/`에 더미데이터(과제·AI 과제·사용자)가 만들어집니다. `data/`는 git에 올라가지 않습니다.
- 시연 계정·공통 비밀번호는 발표·운영 전에 지워야 합니다 (`auth_users.py`의 `DEFAULT_SEED_PASSWORD`, `login.html` 안내 문구).

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 첫 화면 → `dashboard.html`로 이동 |
| `dashboard.html` | 대시보드 화면 |
| `progress.html` | 내 과제 진행률 화면 |
| `ai-projects.html` | AI 과제 목록 화면 (등록·수정·삭제) |
| `overall.html` | 세부 진행 현황 (대시보드 하위) |
| `task-detail.html` | 과제 상세 (첨부 파일·상세 현황·변경 이력) |
| `storage.js` | 저장 모듈 (서버 API ↔ localStorage 자동 전환) |
| `file-storage.js` | 첨부 파일 모듈 (`/api/tasks/<id>/files` ↔ IndexedDB 자동 전환) |
| `ai-storage.js` | AI 과제 저장 모듈 (`/api/ai-projects` ↔ localStorage) |
| `server.py` | 저장 서버 + REST API (`/api/tasks`, `/api/ai-projects`) + 로그인 검사 |
| `auth_users.py` | A01 로그인·회원가입·사용자 관리 API, 사용자 저장소 |
| `auth.js` | 화면 공용 로그인 확인·계정 메뉴·미리보기 모드 |
| `login.html` `signup.html` `mypage.html` `admin-users.html` `settings.html` | 로그인 / 회원가입 / 내 정보 / 사용자 관리 / 사이트 설정 (`common.css` 스타일) |
| `similar.html` `similar_llm.py` | 유사과제 탐색 화면 / AI(LLM) 연결 API (`/api/llm/*`, `/api/similar/group`) |
| `xlsx_util.py` `work_log.py` | 엑셀(.xlsx) 쓰기·읽기 / AI 과제 삭제·올리기 작업 기록 |
| `demo-data.json` `demo-data.js` | 더미데이터 / 오늘 날짜 기준으로 바꾸는 모듈 (서버는 `server.py`의 `demo_items()`가 같은 규칙) |
| `data/tasks.json` | 저장된 과제 데이터 |
| `data/ai_projects.json` | 저장된 AI 과제 데이터 |
| `data/users.json` `data/audit.log` | 사용자(비밀번호는 해시) / 사용자 관리 처리 이력 |
| `data/llm_config.json` | 사이트 설정의 AI 서비스 연결 정보(API 키 포함, git에 올라가지 않음) |
| `data/work_log.jsonl` | AI 과제 삭제·엑셀 올리기 작업 기록 |
| `data/files/<과제id>/` | 첨부 파일 원본 (목록은 과제의 `files` 항목) |
